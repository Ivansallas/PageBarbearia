# Page Barbearia

Página estática para barbearia — site institucional com informações sobre serviços, contato, agenda etc.

---

## Sobre

Este projeto é um site simples para uma barbearia. Ele contém páginas que exibem:

- Página inicial (index)  
- Página de produtos ou serviços  
- Página de contato  
- Página de agenda  
- Estilos (CSS) básicos  
- Reset de estilos (CSS)  

---

## Tecnologias

- HTML  
- CSS  
- Arquivos estáticos (não há back-end)

- PageBarbearia/
│
├── index.html # Página inicial
├── produtos.html # Serviços ou produtos oferecidos
├── contato.html # Informações de contato
├── agenda.html # Formulário ou calendário de agenda
├── style.css # Estilo personalizado
├── reset.css # Reset de estilos CSS
└── imagens/ # Contém as imagens usadas no site
